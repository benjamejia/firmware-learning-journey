# 🚀 Firmware & Embedded Systems Learning Journey

Este repositorio es una bitácora de mi camino para estudiar sistemas embebidos, enfocado en desarrollo de firmware, controladores de periféricos (bare-metal) y sistemas operativos en tiempo real (RTOS). 

El objetivo principal es desarrollar las habilidades técnicas requeridas para posiciones de Internship en empresas como NXP e Intel.

## 📋 Roadmap de Aprendizaje / Progreso
- [x] Módulo 1: Manipulación de bits y estructuras en C.
- [ ] Módulo 2: Drivers Bare-Metal (GPIO y UART).
- [ ] Módulo 3: Protocolos de Comunicación (I2C con sensores y SPI).
- [ ] Módulo 4: Implementación de FreeRTOS.

## 📂 Estructura del Repositorio
*   `/practices`: Código fuente de cada periférico y driver desarrollado desde cero.
*   `/docs`: Resúmenes técnicos, diagramas de flujo y notas de hojas de datos (datasheets).
